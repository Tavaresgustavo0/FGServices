# F. Great Services

Site estatico em ingles e portugues. Todos os arquivos ficam diretamente nesta pasta, sem subpastas, dependencias ou build.

## Vercel

Importe o repositorio e use:
- Framework Preset: Other.
- Root Directory: ./ (a pasta contendo index.html).
- Build Command: vazio.
- Install Command: vazio.
- Output Directory: .

O vercel.json ja define essas configuracoes. Clique em Deploy.
Tambem pode executar npx vercel --prod no terminal desta pasta e fazer login.
Nao precisa de variaveis de ambiente ou chaves de API.

Abra index.html para visualizar localmente. Fotos, fontes e mapa precisam de internet.
O WhatsApp prepara a mensagem; o Instagram permite copiar o texto e abrir a conversa. O visitante confirma o envio no aplicativo.
As fotos sao ilustrativas. O endereco comercial usado no mapa ainda precisa de confirmacao para visitas presenciais.
